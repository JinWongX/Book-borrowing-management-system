## 测试执行建议

1. **冒烟测试**：优先执行 TC-AUTH-001、TC-BOOK-001、TC-BORROW-001、TC-AUDIT-001、TC-LEND-001、TC-RETURN-001、TC-RBAC-001。
2. **回归测试**：在每次代码变更后执行所有 P0/P1 用例。
3. **自动化建议**：后端接口可使用 `pytest + httpx/requests` 编写自动化脚本，前端核心流程可使用 Playwright/Cypress 录制执行。
